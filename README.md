# 干饭签小程序

干饭签是一个微信原生小程序项目，目标是做成一个可爱的“求签式”吃饭决策工具：当用户纠结午餐或晚餐吃什么时，可以点击“求一签”随机抽取一道菜，并配上一句轻松的签文。

## 项目定位

- **项目类型**：微信原生小程序
- **技术栈**：JavaScript + WXML + WXSS + JSON
- **目标用户**：每天纠结“吃什么”的打工人、学生
- **设计风格**：手绘可爱卡通风，暖色系，强调轻松和治愈感
- **后端方案**：第一阶段即使用微信云开发，业务数据默认存储到云数据库

## 核心功能规划

1. **首页抽签**
   - 选择午餐或晚餐
   - 点击“求一签”随机抽取食物
   - 展示菜品、图片和签文
   - 支持“再求一次”和“就吃这个”
   - 支持每日抽签次数限制

2. **我的页面**
   - 管理我的菜单
   - 启用或禁用食物
   - 查看已吃记录
   - 查看本周吃饭统计
   - 进入设置页面

3. **分包页面**
   - 编辑或新增食物
   - 查看全部记录
   - 设置抽签规则
   - 关于项目

## 开发规则入口

开发前必须阅读：

- [AGENTS.md](./AGENTS.md)
- [docs/开发规范.md](./docs/开发规范.md)

关键约定：

- 全程使用中文沟通和提交说明。
- 遵循 KISS 原则，非必要不要过度设计。
- 第一阶段即使用微信云开发。
- 云数据库访问必须统一封装。
- 主要函数需要写注释。
- 修改前后检查 `git status --short`。
- 不主动提交或推送，除非用户明确要求。

## 开发顺序

建议按以下顺序推进：

1. 基础框架与微信云开发初始化
2. 云数据库访问封装与常量定义
3. 默认数据、日期、抽签、统计等工具函数
4. 基础组件
5. 首页抽签流程
6. 我的页菜单、记录和统计
7. 分包页面
8. 动画、音效、适配和性能打磨
